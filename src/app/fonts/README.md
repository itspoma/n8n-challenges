# Geomanist webfonts

These files are unmodified WOFF2 assets served by the public n8n Academy stylesheet:

- `geomanist-light.woff2` — weight 300
- `geomanist-regular.woff2` — weight 400
- `geomanist-medium.woff2` — weight 500
- `geomanist-bold.woff2` — weight 700

Source: <https://learn.n8n.io/static/edx-theme-rg/fonts/>
