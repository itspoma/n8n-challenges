## Головне оновлення: кешування запитів у ноді Anthropic в n8n

![Рука встановлює трипозиційний перемикач поряд зі стопкою закешованих паперів, що зображує опцію кешування ноди Anthropic.](/blog/uk/article-71af203f-f347-41ab-9201-e3a6230cc547/e189fc9fb2533c6e67ea6a2caf3518bf5bba8b4b418e19d5b416078a4eda116e.png)

Рука встановлює перемикач на коробці поряд зі стопкою напівпрозорих закешованих аркушів паперу та рядом петльових стрілок.

Центральним елементом цих нотаток випуску n8n 2.42 є нова опція Prompt Caching (кешування запитів), додана до операції Text → Message ноди Anthropic. Опція пропонує три налаштування і за замовчуванням постачається вимкненою, тож воркфлоу, які вже використовують ноду Anthropic, поводитимуться точно так само, як і раніше, доки хтось не увімкне цю функцію свідомо. Після увімкнення звітність про використання токенів ноди також починає включати окремі лічильники токенів для створення кешу та читання з кешу.

- Disabled — кешування вимкнено, налаштування за замовчуванням
- 5 Minutes — кеш зберігається п’ять хвилин між запитами
- 1 Hour — кеш зберігається одну годину між запитами

У нотатках випуску n8n зазначено, що за ввімкненого кешування повторювані цикли викликів інструментів і великі системні запити (system prompts) тарифікуються за зниженими ставками для закешованої частини токенів. Ми з оптимізмом дивимося на те, що це означає для воркфлоу, які циклічно повторюють виклики інструментів або надсилають великий, здебільшого незмінний системний запит під час кожного запуску: кешування такого повторюваного вмісту — це саме той сценарій, на який і розрахована ця функція.

Реліз n8n на GitHub підтверджує те саме доповнення у списку Features, відстежуване як pull request 35804, назва якого вказує на додавання кешування запитів до операції Message.

## Контекст: що означає кешування запитів для запитів до Claude

Кешування запитів — це не нова функція, що з'явилася лише у версії n8n 2.42. Власна документація n8n для окремої піднодди Anthropic Chat Model вже пропонувала ідентичне налаштування Disabled, 5 Minutes або 1 Hour, яке використовується для кешування системного запиту, визначень інструментів та історії розмови між запитами для [розмовних агентів](<https://n8n-challenges.app/uk/blog/posibnyk-z-ai-agent-u-n8n-stvorit-svoho-pershoho-ahenta>).

Оскільки нова опція операції Message тепер відповідає налаштуванню, яке вже мали розробники розмовних агентів, ми вважаємо, що варто узгодити тривалість кешування в обох нодах в межах одного воркфлоу, а не залишати одну з кешуванням, а іншу без нього.

Sources: [Anthropic Chat Model | Nodes | n8n Docs](<https://docs.n8n.io/integrations/builtin/cluster-nodes/sub-nodes/n8n-nodes-langchain.lmchatanthropic>)

## Кого це стосується

Нотатки випуску описують це оновлення переважно в термінах операції Message ноди Anthropic, а не за планом чи типом розгортання. Ми б утрималися від припущення, що кожна команда отримає це одразу, оскільки анонс просто не говорить нічого з цього приводу.

Власні вказівки n8n щодо версіонування описують збільшення MINOR-версії, наприклад перехід від 2.41 до 2.42, як додавання функціональності у зворотносумісний спосіб, а не внесення критичних змін; ця сторінка з вказівками заархівована й більше не оновлюється, тож тут вона розглядається лише як загальний контекст, а не як твердження, специфічне для версії 2.42.

- Команди, що використовують операцію Message ноди Anthropic для ШІ-агентів
- Команди, чиї воркфлоу повторюють виклики інструментів або повторно надсилають довгі системні запити
- Це може стосуватися команд на будь-якому плані, але в анонсі не вказано, які саме плани чи типи розгортання отримують цю зміну

Sources: [Release notes | Changelog | n8n Docs](<https://docs.n8n.io/changelog/release-notes>), [Release notes 2.x | Changelog | n8n Docs](<https://docs.n8n.io/changelog/release-notes-2.x>)

Визначити, чи варто кешувати повторювані цикли викликів інструментів або довгі системні запити у ваших власних воркфлоу з нодою Anthropic, — це саме той практичний навик, якому наша програма AI Agents with n8n навчає команду, працюючи з власними інструментами та даними команди. ## Інші 13 нових функцій n8n 2.42 — коротко

Окрім кешування запитів у ноді Anthropic, нотатки випуску n8n 2.42 нараховують ще 13 функцій у цьому самому оновленні. Сторінка релізу на GitHub наводить один конкретний приклад серед них: n8n зробив SSO основним варіантом на сторінці входу, коли увімкнено вхід через SAML або OIDC.

В інших випадках список на GitHub наводить лише короткі, однорядкові назви комітів для решти змін, тому ця стаття не переказує кожну з них як окреме твердження понад те, що названо в самому анонсі.

- Кешування запитів у ноді Anthropic — головне оновлення, описане вище
- SSO зроблено основним варіантом входу, коли увімкнено вхід через SAML або OIDC
- Решта пунктів, вказаних у релізі n8n на GitHub лише як короткі назви комітів

## Що читачам варто зробити зараз

Як редакційна порада, а не щось рекомендоване самими нотатками випуску: командам, чиї воркфлоу з нодою Anthropic повторюють цикли викликів інструментів або надсилають великі, здебільшого незмінні системні запити, варто розглянути ввімкнення нової опції Prompt Caching, пам'ятаючи, що її потрібно вмикати окремо для кожної ноди, оскільки за замовчуванням вона вимкнена.

Перш ніж вмикати її, варто ознайомитися з новою опцією операції Message поряд з ідентичним налаштуванням уже наявної піднодди Anthropic Chat Model, щоб обидві були налаштовані з однаковою тривалістю кешування в межах одного воркфлоу.

Команди із самостійним розгортанням (self-hosted) можуть розглядати 2.42 як рутинне мінорне оновлення, що відповідає власній політиці зворотносумісних MINOR-версій n8n, і мають перевірити версію власного інстансу після оновлення, щоб підтвердити наявність опції Prompt Caching, перш ніж покладатися на неї.

- [ ] Перевірте, чи воркфлоу з нодою Anthropic повторюють цикли викликів інструментів або повторно надсилають великі системні запити
- [ ] Увімкніть опцію Prompt Caching для кожної ноди окремо, оскільки за замовчуванням вона вимкнена
- [ ] Узгодьте тривалість кешування і в операції Message, і в піднодді Chat Model
- [ ] Перегляньте список виправлень помилок у релізі на GitHub перед оновленням продакшн-інстансу
- [ ] Переконайтеся, що опція Prompt Caching наявна на self-hosted інстансі після оновлення

## Чого не говорять нотатки випуску n8n 2.42

У цих нотатках випуску n8n 2.42 просто не вказано кілька деталей. Анонс не повідомляє, на які плани чи типи розгортання поширюється зміна в ноді Anthropic, а також не вказує терміни її впровадження.

Також не наведено конкретного відсотка зниження вартості для закешованих токенів; зазначено лише в якісних термінах, що закешовані токени тарифікуються за зниженими ставками. Усе, що виходить за межі функцій, названих у самому анонсі, включно з результатами для інших редакцій чи хмарних планів, тут просто не вказано.

- Які плани чи типи розгортання n8n отримують зміну в ноді Anthropic і за яким графіком
- Точний відсоток зниження вартості для закешованих токенів
- Будь-які зміни, що виходять за межі функцій, названих у самому анонсі
