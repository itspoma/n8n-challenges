## Що змінилося: рекомендація безпеки n8n Chat Trigger XSS

Якщо ви публікуєте чат-віджет за допомогою вузла Chat Trigger в n8n, варто уважно прочитати рекомендацію безпеки n8n Chat Trigger XSS, опубліковану на GitHub 30 вересня 2026 року. Вона має ідентифікатор GHSA-x5cw-hm7v-q7mj і описує вразливість зі збереженим міжсайтовим скриптингом (stored XSS) у параметрі customCss вузла Chat Trigger на хостинг-сторінках чату. Огляд безпеки GitHub за 2026 рік для репозиторію n8n-io/n8n наводить ту саму рекомендацію як опубліковану 30 вересня 2026 року дослідником на ім'я Matsuuu, з рівнем серйозності High (високий). [Власна оцінка CVSS v4 у рекомендації, опублікована 30 вересня 2026 року](<https://github.com/n8n-io/n8n/security/advisories/GHSA-x5cw-hm7v-q7mj>), визначає загальну серйозність на рівні 7,0.

Згідно з рекомендацією, вразливість працює через збережену ін'єкцію: значення customCss, яке вводить редактор робочого процесу, зберігається у вузлі Chat Trigger, а потім відображається на публічній хостинг-сторінці чату. На хостинг-сторінці чату, опублікованій без автентифікації користувачів n8n, рекомендація зазначає, що вміст customCss зловмисника виконується для будь-якого відвідувача, який завантажує цю сторінку. Фактично, неавтентифікована хостинг-сторінка чату стає точкою доставки для виконання довільного коду, оскільки браузер сприймає збережене значення стилізації як код, а не як звичайний CSS — це і є суть проблеми, що лежить в основі цієї рекомендації безпеки для хостингу чату n8n.

Sources: [Overview · n8n-io/n8n · GitHub](<https://github.com/n8n-io/n8n/security>), [n8n Chat Trigger Stored XSS via customCss Parameter on Hosted-Chat Page · Advisory · n8n-io/n8n · GitHub](<https://github.com/n8n-io/n8n/security/advisories/GHSA-x5cw-hm7v-q7mj>)

## Які конфігурації n8n Chat Trigger уразливі через customCss

Рекомендація вказує, що версії n8n нижче 1.123.83, 2.42.1 та 2.41.4 уразливі до цієї проблеми n8n chat trigger xss, яку в рекомендації також називають вразливістю n8n customCss на хостинг-сторінці чату, тоді як версії на рівні цих номерів або вище позначені як виправлені. У ній не зазначено, чи мають той самий недолік старіші застарілі основні версії, що виходять за межі цієї нумерації. Як редакційне зауваження: командам, що використовують нетипові історичні збірки, варто самостійно перевірити свою версію щодо цих порогових значень.

Вплив також залежить від того, як опубліковано конкретну сторінку Chat Trigger. У таблиці нижче підсумовано те, що рекомендація повідомляє про кожну конфігурацію.

**Що рекомендація повідомляє про уразливі та невразливі конфігурації Chat Trigger**

| Конфігурація | Висновок рекомендації |
| --- | --- |
| Сторінка чату з автентифікацією «None» | Уразлива: впроваджений customCss виконується для будь-якого відвідувача, який завантажує сторінку |
| Сторінка чату з увімкненим n8n User Auth | Не уразлива, за даними рекомендації |
| Інсталяція нижче 1.123.83 / 2.42.1 / 2.41.4 | Уразлива |
| Інсталяція на рівні цих версій або вище | Виправлено |

Рекомендація називає лише n8n User Auth як налаштування, яке не є уразливим. Вона не зазначає, чи забезпечує режим Basic Auth такий самий захист. Ми б розглядали Basic Auth як непідтверджений варіант, а не припускали, що він блокує ту саму атаку, оскільки рекомендація конкретно вказує, яке саме налаштування є безпечним.

## Довідково: як працює налаштування автентифікації Chat Trigger в n8n

Документація вузла Chat Trigger n8n зазначає, що вибір значення None для автентифікації чату означає, що для використання чату не потрібен вхід у систему. Це довідкова інформація про продукт, а не зміст рекомендації безпеки, і вона взагалі не згадує про вразливість customCss.

Та сама документація зазначає, що вибір [n8n User Auth](<https://n8n-challenges.app/uk/blog/cheklyst-bezpeky-n8n-dlya-spilnoho-self-hosted-instansu>) обмежує доступ до чату лише користувачами, які вже увійшли в облік n8n. Це корисний контекст для розуміння налаштування, яке рекомендація визначає як невразливе, але сама документація не висловлює позиції щодо безпеки.

Sources: [Chat Trigger | Nodes | n8n Docs](<https://docs.n8n.io/integrations/builtin/core-nodes/n8n-nodes-langchain.chattrigger>)
