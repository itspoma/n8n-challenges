## What n8n's AI Workflow Builder Beta Was And How It Worked

The n8n AI Workflow Builder beta was a chat-based feature for n8n Cloud that let users describe an automation goal in plain language and get a starting workflow back instead of a blank canvas. According to n8n's official documentation, the feature let users create, refine, and debug workflows using natural language descriptions of their goals, turning a written request into a set of connected nodes. For a learner or a busy technical lead, that is the real draw: skip the blank-canvas stare and start from something that already resembles a workflow.

This review covers n8n's own native feature rather than the separate third-party "n8n workflow builder ai beta chrome extension," which is a different product with its own listing and is not covered here.

Two operational details matter before trusting it with real data. n8n's documentation states that each message asking the builder to create or modify a workflow counts as a single billable interaction, so a back-and-forth refining session uses credits message by message rather than per finished workflow. The same documentation states that credential details are not sent to the underlying AI model, which matters for any team wary of exposing API keys or tokens to a third-party model provider.

Independent testing found the builder quick to draft a skeleton workflow but still reliant on a knowledgeable user to guide and fix it.

Beyond the official description, the clearest independent look at how the builder performed in practice comes from AI Fire's November 2025 stress test: one practitioner's own four self-run tests, published on a page that also promotes AI Fire's own paid course, rather than a controlled or peer-reviewed study. With that limitation in mind, AI Fire described the n8n AI Workflow Builder beta as a skeleton generator: fast at producing a workable starting structure, but not a finished workflow a team could ship untouched.

Max Anh, who wrote up that stress test for AI Fire, put the trade-off in his own words directly below.

> “It's a powerful accelerator but it's not a magic wand. It requires guidance, troubleshooting and a human who understands the fundamentals.”

## n8n AI Workflow Builder Beta Availability And Credit Limits On n8n Cloud

The n8n AI Workflow Builder beta was never available everywhere at once. According to [n8n's community forum announcement from October 13, 2025](<https://community.n8n.io/t/introducing-ai-workflow-builder-beta/204919>), the rollout reached n8n Cloud builders on Trial, Starter, and Pro plans during that initial week, with no mention of self-hosted instances.

A separate community forum reply from November 2025 confirmed that gap directly: a community member stated that the builder was not available for self-hosted instances and was cloud-only at that time. We'd be cautious about leaning on a feature still gated to specific cloud plans and tiers as the backbone of a team's workflow-building process, since its reach was narrower than n8n's platform as a whole.

Credit limits also varied by plan. A community forum reply from December 2025 reported figures it said came from n8n's own release notes, which is the most specific breakdown available in the sources checked for this review:

**Credit caps reported for the beta by plan, per a community forum summary of n8n's release notes (December 2025)**

| Plan | Reported credits |
| --- | --- |
| Trial | 20 credits total |
| Starter | 50 credits per month |
| Pro | 150 credits per month |

## Important Update: n8n Says The Builder Has Been Superseded

The feature this article is named for, the n8n AI Workflow Builder beta, no longer exists in that form. n8n's own blog, posted in September 2026, states plainly that n8n Assistant supersedes the AI Workflow Builder. The same post explains the functional difference: the old builder generated a workflow once and stopped, while the newer Assistant keeps iterating with the user across a conversation.

That framing was echoed earlier inside n8n's community: in a community FAQ from July 2026, an n8n team member stated that the new AI Assistant replaces the AI Workflow Builder, months before the public blog post made the same point.

n8n's current documentation describes the successor, n8n Assistant, as a chat-based agent that helps create, edit, test, and troubleshoot workflows from natural language. That documentation still cautions that generated workflows may need manual review and correction while the Assistant remains in Preview, and n8n's deployment docs state it isn't yet ready for n8n Cloud Enterprise or self-hosted Enterprise.

Pricing has shifted too: n8n's current [pricing page](<https://n8n-challenges.app/en/blog/n8n-io-pricing-what-a-team-actually-pays-in-production>) lists monthly credits for the Starter plan under the renamed Assistant feature rather than the old AI Workflow Builder label. We're optimistic that an assistant built to keep iterating with a user is a better fit for how automation actually gets built than a tool that drafts once and walks away.

## Who This Is Ready For Today, And What To Verify First

Given this history, the underlying capability is worth separating from the name. If a reader's n8n Cloud workspace once showed the AI Workflow Builder beta, or now shows the newer Assistant that replaced it, the skeleton-generator description from AI Fire's independent testing still applies to what either tool hands back. That makes either one a reasonable aid for a technical lead sketching a first pass, or a learner exploring what a task might need.

- [ ] Treat any AI-generated draft as a skeleton that needs manual review before production use
- [ ] Write specific prompts that state the trigger, tools, settings, and expected output
- [ ] Manually check optional node settings and output structure on any third-party API call
- [ ] Confirm whether your workspace shows the AI Workflow Builder or n8n Assistant, since availability and credits differ
- [ ] Self-hosted teams should check n8n's current docs directly rather than assume beta-era Cloud limits still apply
